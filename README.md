# bun-pug-sass-template

**Modern web template** with hot reloading for Pug/Sass, powered by Bun's lightning-fast toolkit.  
Perfect for prototyping static sites or simple web applications.

## ✨ Features

- **Pug** templating with HTML5 boilerplate
- **Sass/SCSS** support with auto-prefixing
- Instant HMR (Hot Module Replacement)
- Live reload for Pug/Sass changes
- Production-ready minification

<!-- bun create <user>/<repo> -->

To install dependencies:

```bash
bun install
```

To run server with hot module replacement AND compile Pug and Sass and watch for changes:

```bash
bun run dev
```
